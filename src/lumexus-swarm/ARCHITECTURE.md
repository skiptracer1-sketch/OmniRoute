# Lumexus Native Swarm v0.1

This module is a clean-room Lumexus implementation. No Pentest-Swarm-AI source code is included.

## Runtime path

Crazy E Decision Authority -> Lumexus Brain -> Security Swarm Runtime -> OmniRoute adapter -> policy-enforced Tool Gateway -> authorized executor.

Runtime Pulse is projected from mission, agent, finding, approval and event state.

## Safety boundary

- Mission scope is mandatory.
- Out-of-scope tool requests are denied before executor invocation.
- High/critical-risk requests enter the Decision Queue and do not execute.
- A global kill switch blocks further tool evaluation.
- The default Security Agent Registry contains no exploit or production-mutation capability.
- v0.1 is intended for authorized assets and isolated security validation.

## Roles

Recon, surface analysis, vulnerability classification, verification, remediation planning, regression and reporting.
